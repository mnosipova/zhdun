# Ждун в Суздале 🛋️

Мини-игра: угадай цену аренды на Авито в Суздале. Превед, медвед!

Показываем 10 активных лотов (квартиры/дома из Суздаля), ты дёргаешь бегунок с ценой за сутки,
жмёшь «ОЦЕНИТЬ» — узнаёшь реальную цену, разницу, баллы и ссылку на настоящее объявление.
В конце — вердикт: «Верните цены 2007-го», «Сын маминой подруги» или «Олигарх из 2007-го».

## Балльная система

| Отклонение твоей цены от реальной | Баллы |
|---|---|
| ≤ 5% | 100 |
| ≤ 10% | 80 |
| ≤ 20% | 60 |
| ≤ 35% | 40 |
| ≤ 60% | 20 |
| > 60% | 0 |

Максимум за игру: 1000 баллов. Вердикт считается по среднему знаковому отклонению:
±10% и меньше — «Сын маминой подруги», стабильно ниже — «Верните цены 2007-го», стабильно выше — «Олигарх из 2007-го».

## Файлы

- `index.html` — разметка (3 экрана: старт, лот, итог)
- `style.css` — стили (мемы 2010, mobile-first, одна карточка на экран)
- `app.js` — логика игры
- `data.js` — сгенерированные данные из выгрузки объявлений Авито (только активные лоты)

## Публикация на GitHub Pages

Статический сайт без сборки — деплоится за минуту:

1. Создай репозиторий на GitHub, залей эти 5 файлов в корень (или в папку `docs/`).
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
3. Через ~1 минуту сайт будет на `https://<username>.github.io/<repo>/`.

Или локально проверить: `python3 -m http.server 8000` в папке проекта → http://localhost:8000

## Примечания

- Картинки грузятся напрямую с CDN Авито (`img.avito.st`), с `loading="lazy"` для всех фото кроме первого — страницы открываются легко.
- Данные в `data.js` — снапшот активных объявлений на момент выгрузки; ссылки ведут на реальные лоты.
- Все вычисления на клиенте, никаких зависимостей и сборки.
